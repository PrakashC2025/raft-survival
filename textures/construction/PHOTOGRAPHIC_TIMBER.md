# Photographic timber atlas

Generated for this project on 2026-10-07 with the built-in imagegen tool after the owner requested a realistic handcrafted wood feel. Original generated content; no downloaded timber photograph or reference-game art. This is generated photographic-style albedo, not a photograph of the game or a scanned PBR material. Runtime rounded geometric normals, seams, palette variation, damp roughness/specular masks and lighting produce the in-game appearance.

Final asset: `textures/construction/timber_photographic_atlas.png`, the cleaner second edit below. Actual source dimensions: 1254 by 1254 pixels (the initial generation prompt requested 2048). Four equal horizontal strips: salvaged pine, cedar, walnut and hemp. Retained Godot import settings use VRAM compression, High Quality, a 1024 Size Limit and mipmaps, currently producing desktop BPTC and Android ASTC. The generated source PNG is unmodified. `wood_planks.gdshader` samples each strip with margins and anisotropic filtering. Flat per-instance seeds prevent the fragment hash from speckling the grain. `construction_visual.gd` builds shared rounded timber meshes while preserving sockets and collision sizes.

The earlier code-generated `timber_atlas.png` remains an optional fallback; `prepare_visual_overhaul.py` does not overwrite the selected photographic asset.

# Original edible garden assets

`garden_atlas.png` is an original transparent 800 x 1120 actual-model render, with seven rows (Tomato, Bell Pepper, Cucumber, Pumpkin, Strawberry, Corn, Papaya) and five 160px columns (whole produce, sliced produce, dry seeds, wet seeds, rare wooden supply box). Runtime mappings are in `scripts/garden_items.gd` and `scripts/item_art.gd`. The existing photographic whole Tomato icon remains selected at runtime. The Tomato-row crate tile is an unused fallback; actual garden boxes cover the six new crops.

New crop/fruit/seed geometry, UV skin/vein shader, cut faces, drying tray and kitchen knife/board geometry are original project code, dedicated under CC0 1.0. Files: `scripts/garden_visual.gd`, `shaders/garden_skin.gdshader`, `scripts/seed_drying_tray.gd` and the garden preparation additions in `scripts/survival_action.gd`. Timber reuses the previously credited photographic construction atlas; hands, character rig and existing Tomato produce retain their existing asset provenance. No downloaded photographs, paid models or other games' assets are included.

Eight 160px recipe pictures in `textures/ui/food/` are original transparent renders of the existing meal bowl with original sliced-ingredient geometry: `roasted_pumpkin`, `roasted_corn`, `garden_vegetable_stew`, `cucumber_tomato_soup`, `papaya_banana_mash`, `strawberry_compote`, `pepper_fish_skillet`, `pumpkin_corn_soup`. The new 160px `textures/ui/stations/seed_drying_tray.png` renders the actual wooden tray and seeds. These do not change existing recipe photographs or their atlas regions.

Regenerate with `tools/preview_survival_update.ps1 -TestScript garden_cycle_smoke.gd -SilentAudio`; this uses isolated saved data and native Mobile/D3D12 SubViewports. Then run `tools/import_food_icons.ps1 -IconFolder garden`, `food` and `stations` separately. These import through small real directories without scanning/deleting source-test junctions. No APK export is involved.
